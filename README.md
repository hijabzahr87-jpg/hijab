# Haute Parfumerie · Maison Fragrance Store

A luxury artisanal fragrance e-commerce web application inspired by Haute Parfumerie aesthetics, crafted with Material Design 3 and Tailwind CSS.

## 🌸 Live Architecture & Screens

1. **Discovery (Maison Home)** (`/discovery_maison_parfumerie/`)
   - Editorial campaign showcase (*L'Heure Dorée*)
   - Interactive olfactory note matrix (Smoky, Woody, Amber, Floral, Citrus)
   - Scrollable flacon carousel & fragrance pyramid evolution
2. **Flacon Details** (`/flacon_details_nuit_de_santal/`)
   - Multi-angle studio visual gallery
   - Sillage and longevity indicators
   - Volume selector (50ml, 100ml, 250ml) & bespoke gold monogram engraving
3. **Fragrance Finder (Olfactory Quiz)** (`/fragrance_finder_olfactory_quiz/`)
   - Multi-stage cadence diagnostic
   - Atmospheric memory selector
   - Tailored scent recommendations & 2ml sample ordering
4. **Atelier Selection (Cart / Bag)** (`/shopping_bag_atelier_selection/`)
   - Handcrafted batch reservation
   - Complimentary sample selection
   - Express checkout & Grasse atelier order confirmation

---

## 🚀 Running Locally

### Option 1: Double-Click Launcher (Windows)
Double-click `start-server.bat` to launch the local server and open http://localhost:3000 in your default browser.

### Option 2: Python Command Line
```bash
python -m http.server 3000
```
Open **[http://localhost:3000](http://localhost:3000)** to view the interactive showcase and mobile device preview.
